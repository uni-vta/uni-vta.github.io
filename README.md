# UVTA project page

Project website for **Unified Visual-Tactile-Action Modeling from Human Demonstrations for Dexterous Manipulation**.

The site is static and deploys directly with GitHub Pages from the repository root.

Live site: <https://uni-vta.github.io/>

Demo section: <https://uni-vta.github.io/#video>

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

Paper, dataset, and code links are intentionally marked as coming soon until their public release.
